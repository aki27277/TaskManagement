# 機能要件・非機能要件・ユースケース

## 1. 機能要件

| # | 機能 | 内容 |
|---|------|------|
| 1 | カラム表示 | 「未着手」「作業中」「完了」の3列を表示 |
| 2 | カード作成 | タイトル（必須）・説明文（任意）を入力して追加 |
| 3 | カード削除 | 不要なタスクを削除 |
| 4 | カード移動 | ドラッグ&ドロップで別カラムへ移動 |
| 5 | データ保存 | ページを閉じても消えない（REST API経由でDBに保存） |
| 6 | カード編集 | タイトルや説明を変更 |
| 7 | 期限日 | タスクに締切を設定 |
| 8 | 優先度 | 高・中・低などのラベル |
| 9 | 並び替え | 優先度順・期限順での並び替え、およびドラッグ&ドロップによる自由な並び替え |

## 2. 非機能要件

| 項目 | 内容 |
|------|------|
| 対応ブラウザ | Chrome 最新版 |
| レスポンシブ対応 | 不要（デスクトップのみ） |
| 認証 | 不要 |
| バックエンド | 必要（REST API） |
| データベース | 必要（RDB） |
| API通信 | フロントエンドからREST APIを呼び出してデータを操作する |

## 3. ユースケース

| # | アクター | ユースケース | 概要 |
|---|---------|-------------|------|
| UC-01 | ユーザー | タスクを作成する | カラムにカードを追加し、タイトル・説明・期限・優先度を入力する |
| UC-02 | ユーザー | タスクを確認する | ボード上のカードを一覧で確認する |
| UC-03 | ユーザー | タスクを編集する | 既存カードのタイトル・説明・期限・優先度を変更する |
| UC-04 | ユーザー | タスクを削除する | 不要なカードをボードから取り除く |
| UC-05 | ユーザー | タスクを進捗移動する | カードをドラッグ&ドロップで別カラムへ移動する |
| UC-06 | ユーザー | タスクを並び替える | 優先度順・期限順、またはドラッグ&ドロップで並び替える |
| UC-07 | ユーザー | データを永続化する | ページを閉じて再度開いてもカードが維持されている（DBに保存） |

## 4. 操作フロー

### UC-01: タスクを作成する

```
1. ユーザーがいずれかのカラム下部の「+ 追加」ボタンをクリック
2. カード作成モーダルが開く
3. タイトルを入力（必須）
4. 説明文を入力（任意）
5. 期限日をカレンダーピッカーで選択（任意）
6. 優先度をセレクトボックスで選択（任意、デフォルト：中）
7. 「追加」ボタンをクリック
   → タイトルが未入力の場合、バリデーションエラーを表示（モーダルを閉じない）
   → 入力済みの場合、カードをカラムに追加してモーダルを閉じる
8. 「キャンセル」ボタンまたはモーダル外クリックでモーダルを閉じる（入力内容は破棄）
```

### UC-03: タスクを編集する

```
1. ユーザーがカード上の編集アイコン（鉛筆）をクリック
2. カード編集モーダルが開く（既存の値がフォームに入力済みの状態）
3. 各フィールドを変更する
4. 「保存」ボタンをクリック
   → タイトルが空の場合、バリデーションエラーを表示（モーダルを閉じない）
   → 正常の場合、変更を反映してモーダルを閉じる
5. 「キャンセル」ボタンまたはモーダル外クリックでモーダルを閉じる（変更は破棄）
```

### UC-04: タスクを削除する

```
1. ユーザーがカード上の削除アイコン（ゴミ箱）をクリック
2. 確認ダイアログが表示される（「本当に削除しますか？」）
3. 「削除」をクリック → カードを削除
4. 「キャンセル」をクリック → 何もせずダイアログを閉じる
```

### UC-05: タスクを進捗移動する

```
1. ユーザーがカードをドラッグ開始（カードが半透明になり掴んでいる状態を示す）
2. 移動先のカラムへドラッグ
3. ドロップ → カードが移動先カラムに追加される
4. カラム外でドロップ → 元の位置に戻る
```

### UC-06: タスクを並び替える

```
【ドラッグ&ドロップによる並び替え（デフォルト）】
1. 同一カラム内でカードをドラッグ
2. 挿入したい位置でドロップ
3. カードがその位置に移動する

【ドロップダウンによる並び替え】
1. カラムヘッダー右端の「並び替え」ドロップダウンから「優先度順」または「期限順」を選択
2. そのカラムのカードが選択した順に並び替わる
3. ドロップダウンはプレースホルダーに戻る
4. 並び替え後もドラッグ&ドロップで自由に順序を変更できる
```
