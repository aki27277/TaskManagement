# 画面仕様

## 1. メイン画面（ボード画面）

```
+------------------------------------------------------------------+
|  タスク管理アプリ                                                  |
|  並び替え: [優先度順 ▼]  [期限順 ▼]                              |
+------------------------------------------------------------------+
|                                                                  |
|  +------------------+  +-----------------+  +-----------------+ |
|  | 未着手  (2)      |  | 作業中  (1)     |  | 完了    (1)     | |
|  +------------------+  +-----------------+  +-----------------+ |
|  | +--------+       |  | +--------+      |  | +--------+      | |
|  | |タイトル|  ✏🗑  |  | |タイトル| ✏🗑  |  | |タイトル| ✏🗑  | |
|  | |説明文  |       |  | |説明文  |      |  | |説明文  |      | |
|  | |📅 期限  |       |  | |📅 期限  |      |  | |📅 期限  |      | |
|  | |🔴 高   |       |  | |🟡 中   |      |  | |🟢 低   |      | |
|  | +--------+       |  | +--------+      |  | +--------+      | |
|  |                  |  |                 |  |                 | |
|  | + カードを追加   |  | + カードを追加  |  | + カードを追加  | |
|  +------------------+  +-----------------+  +-----------------+ |
|                                                                  |
+------------------------------------------------------------------+
```

**各UI要素の説明**

| 要素 | 説明 |
|------|------|
| カラムヘッダー | カラム名とカード枚数を表示。固定（変更不可） |
| カード | タイトル・説明（1行省略）・期限・優先度バッジを表示。ドラッグ可能 |
| 編集アイコン（✏） | ホバー時に表示。クリックで編集モーダルを開く |
| 削除アイコン（🗑） | ホバー時に表示。クリックで削除確認ダイアログを開く |
| + カードを追加 | クリックで作成モーダルを開く。そのカラムがデフォルト選択された状態で開く |
| 並び替えボタン | 優先度順・期限順を選択。ドロップダウン形式 |

## 2. カード作成・編集モーダル

```
+--------------------------------------+
|  カードを追加           [×]          |
+--------------------------------------+
|  タイトル *                          |
|  +----------------------------------+|
|  |                                  ||
|  +----------------------------------+|
|  ※ タイトルは必須です ← バリデーション|
|                                      |
|  説明                                |
|  +----------------------------------+|
|  |                                  ||
|  |                                  ||
|  +----------------------------------+|
|                                      |
|  期限日                              |
|  +----------------------------------+|
|  | yyyy/mm/dd          📅           ||
|  +----------------------------------+|
|                                      |
|  優先度                              |
|  +----------------------------------+|
|  | 中 ▼                             ||
|  +----------------------------------+|
|                                      |
|  [キャンセル]           [追加する]   |
+--------------------------------------+
```

**モーダルの振る舞い**

| 操作 | 挙動 |
|------|------|
| `[×]` ボタンクリック | モーダルを閉じる。入力内容は破棄 |
| モーダル外クリック | モーダルを閉じる。入力内容は破棄 |
| `Escape` キー | モーダルを閉じる。入力内容は破棄 |
| タイトル未入力で追加ボタンクリック | モーダルは閉じない。タイトル入力欄の下に「タイトルは必須です」を赤字表示 |
| 正常に追加 | モーダルを閉じ、該当カラムの末尾にカードを追加 |
| 編集時の初期値 | 既存の値を各フィールドに入力済みの状態で開く |

## 3. 削除確認ダイアログ

```
+--------------------------------------+
|  タスクの削除                        |
+--------------------------------------+
|                                      |
|  「タスクタイトル」を削除しますか？  |
|  この操作は取り消せません。          |
|                                      |
|  [キャンセル]           [削除する]   |
+--------------------------------------+
```

**ダイアログの振る舞い**

| 操作 | 挙動 |
|------|------|
| `[削除する]` クリック | カードを削除してダイアログを閉じる |
| `[キャンセル]` クリック | 何もせずダイアログを閉じる |
| ダイアログ外クリック | 何もせずダイアログを閉じる |
| `Escape` キー | 何もせずダイアログを閉じる |

```
         |
         |── 「+ カードを追加」クリック ──→ [カード作成モーダル]
         |                                        |
         |                               追加する / キャンセル / ×
         |                                        |
         |←───────────────────────────────────────+
         |
         |── カード編集アイコンクリック ──→ [カード編集モーダル]
         |                                        |
         |                               保存 / キャンセル / ×
         |                                        |
         |←───────────────────────────────────────+
         |
         |── カード削除アイコンクリック ──→ [削除確認ダイアログ]
         |                                        |
         |                               削除する / キャンセル
         |                                        |
         |←───────────────────────────────────────+

  ※ 画面遷移はメイン画面のみ。モーダル・ダイアログはオーバーレイ表示。
```
