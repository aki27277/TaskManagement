# 要件定義書

## 1. アプリ概要

Trelloライクなタスク管理アプリ。カンバン形式（カラムとカード）でタスクを視覚的に管理できる。

## 2. ターゲットユーザー

個人利用（自分専用）

## 3. 機能要件

| # | 機能 | 内容 |
|---|------|------|
| 1 | カラム表示 | 「未着手」「作業中」「完了」の3列を表示 |
| 2 | カード作成 | タイトル（必須）・説明文（任意）を入力して追加 |
| 3 | カード削除 | 不要なタスクを削除 |
| 4 | カード移動 | ドラッグ&ドロップで別カラムへ移動 |
| 5 | データ保存 | ページを閉じても消えない（localStorage） |
| 6 | カード編集 | タイトルや説明を変更 |
| 7 | 期限日 | タスクに締切を設定 |
| 8 | 優先度 | 高・中・低などのラベル |
| 9 | 並び替え | 優先度順・期限順での並び替え、およびドラッグ&ドロップによる自由な並び替え |

## 4. 非機能要件

| 項目 | 内容 |
|------|------|
| 対応ブラウザ | Chrome 最新版 |
| レスポンシブ対応 | 不要（デスクトップのみ） |
| 認証 | 不要 |
| バックエンド | 不要（localStorage のみ） |

```
+--------------------------------------------------+
|  タスク管理アプリ                                  |
+--------------------------------------------------+
|  [並び替え: 優先度順 / 期限順]                     |
|                                                  |
|  +----------+  +----------+  +----------+        |
|  | 未着手   |  | 作業中   |  | 完了     |        |
|  +----------+  +----------+  +----------+        |
|  | カード   |  | カード   |  | カード   |        |
|  | タイトル |  | タイトル |  | タイトル |        |
|  | 期限     |  | 期限     |  | 期限     |        |
|  | 優先度   |  | 優先度   |  | 優先度   |        |
|  +----------+  +----------+  +----------+        |
|  | + 追加   |  | + 追加   |  | + 追加   |        |
|  +----------+  +----------+  +----------+        |
+--------------------------------------------------+
```

## 6. 将来の拡張機能（現バージョンでは対象外）

| # | 機能 | 内容 |
|---|------|------|
| 1 | 期限切れ警告 | 期限を過ぎたタスクに警告を表示 |
| 2 | カラムのカスタマイズ | カラムの追加・削除・名前編集が自由にできる |
| 3 | 複数ボード | プロジェクトごとにボードを分けて管理できる |

## 7. 使用技術

| 項目 | 技術 |
|------|------|
| フレームワーク | React + TypeScript |
| ビルドツール | Vite |
| ドラッグ&ドロップ | @hello-pangea/dnd |
| データ保存 | localStorage |
| スタイリング | Tailwind CSS または CSS Modules（未定） |
